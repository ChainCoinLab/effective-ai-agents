# 上下文去重压缩

[返回全局摘要](../README.md) · [返回本组：上下文工程与 RAG](README.md)


## Rule
在送入模型前去除重复、冲突和低价值上下文，并保留必要信息。

## Why
重复内容浪费 token，冲突内容会增加模型选择错误证据的概率。

## Optimize
- 合并重复文档和近重复段落。
- 对长文档提取与任务相关的事实。
- 对冲突信息保留来源、时间和版本。

## Verify
- 对比压缩前后的答案质量和 token 成本。
- 检查压缩是否丢失关键事实。
- 记录被删除或合并的上下文来源。
