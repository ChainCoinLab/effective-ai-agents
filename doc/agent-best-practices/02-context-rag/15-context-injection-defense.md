# 上下文防注入

[返回全局摘要](../README.md) · [返回本组：上下文工程与 RAG](README.md)


## Rule
把检索到的上下文视为不可信数据，不允许其覆盖系统指令和安全规则。

## Why
知识库、网页和用户上传文件可能包含恶意指令。模型若执行这些内容，会产生越权或泄露风险。

## Optimize
- 在 Prompt 中声明上下文只提供事实，不提供指令。
- 清洗或标记可疑内容。
- 对敏感操作增加工具权限和人工确认。

## Verify
- 用包含“忽略以上规则”的文档测试。
- 检查模型是否只提取事实，不执行上下文指令。
- 审计敏感工具调用是否有独立授权。
