# 检索为空策略

[返回全局摘要](../README.md) · [返回本组：上下文工程与 RAG](README.md)


## Rule
定义检索为空或低置信度时的固定处理方式。

## Why
没有空检索策略时，模型容易用常识或猜测填补知识库缺口，造成不可追溯答案。

## Optimize
- 设置最低召回阈值和低置信度判断。
- 返回“未找到足够证据”而不是编造答案。
- 提供改写查询、扩大范围或转人工的路径。

## Verify
- 使用知识库不存在的问题测试。
- 检查模型是否明确说明无证据。
- 监控空检索后的用户追问和人工升级率。
