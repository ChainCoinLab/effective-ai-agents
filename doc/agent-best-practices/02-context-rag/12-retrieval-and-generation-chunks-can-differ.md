# 检索 chunk 和生成 chunk 可以不同

[返回全局摘要](../README.md) · [返回本组：上下文工程与 RAG](README.md)


## Rule
允许使用较小 chunk 做检索，再扩展为更完整的上下文给生成模型。

## Why
小 chunk 有利于精准召回，但生成答案常需要前后文、定义、表格说明或完整流程。

## Optimize
- 检索阶段使用精细粒度索引。
- 生成阶段按命中位置扩展相邻段落或父级章节。
- 保留命中片段和扩展片段的对应关系。

## Verify
- 检查扩展后上下文是否仍与问题相关。
- 评估小 chunk 检索和扩展上下文生成的组合效果。
- 监控扩展带来的 token 成本。
