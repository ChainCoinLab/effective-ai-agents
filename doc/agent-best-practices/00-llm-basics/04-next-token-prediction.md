# 04. 语言模型为什么预测下一个 token

[返回本章](README.md)

## 核心问题

为什么大模型的核心任务是 next-token prediction？

## 推导线索

```text
语言天然是序列
→ 当前 token 和前面的上下文有关
→ 可以把语言建模成条件概率
→ P(下一个 token | 前面的 tokens)
→ 模型输出的是所有候选 token 的概率分布
→ 生成就是不断选择 token 并接回上下文
```

## 本节要讲清楚

- 语言模型是什么
- 条件概率是什么
- logits 和 probability 是什么
- 为什么输出是概率分布
- 为什么生成是一个循环过程
