# 02. 从现实对象到特征向量

[返回本章](README.md)

## 核心问题

机器怎么处理图片、声音、文字这些现实对象？

## 推导线索

```text
机器只能计算数字
→ 房子可以变成面积、楼层、位置等特征
→ 图片可以变成像素矩阵
→ 声音可以变成波形或频谱
→ 复杂对象最终都要变成向量
→ 好的向量表示会保留对任务有用的信息
```

## 本节要讲清楚

- 特征是什么
- 向量是什么
- 为什么图片天然适合变成矩阵
- 为什么文字比图片更麻烦
- 表示学习解决的是什么问题

## 连接到下一节

图片的像素本身就是数字，但文字是离散符号。接下来要解决：词、字或 token 怎么变成模型能计算的向量。
