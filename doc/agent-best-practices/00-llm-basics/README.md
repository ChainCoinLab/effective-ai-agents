# 大模型与 Agent 基础

[返回全局摘要](../README.md)

这一章先建立一个基础心智模型：大语言模型不是数据库，也不是严格按规则执行的程序。它更接近一个经过大规模文本、代码和多模态数据训练出来的概率预测机器：给定输入和上下文，它计算下一个 token 以及后续 token 的概率分布，再按解码策略生成输出。

这也是为什么 AI 工程不能只写一个 Prompt 就结束。只要系统核心是概率预测，就必须围绕它建立上下文管理、评测、工具验证、权限控制、观测和反馈闭环。

## 工程目标：让概率预测机器稳定工作

把这些基础连起来，可以看到 Agent 工程的主线：

```text
Prompt 优化
-> 上下文工程
-> 记忆与状态
-> 工具调用
-> 角色与职责管理
-> 错误恢复
-> 长时间运行
-> 评测、观测、反馈闭环
```

AI 工程的目的不是幻想消除概率性，而是把概率预测机器包进一个稳定的软件系统里：

- 用 Prompt 定义任务边界。
- 用上下文提供可靠依据。
- 用记忆和状态保持长期连续。
- 用工具连接真实世界。
- 用权限控制外部副作用。
- 用角色分工降低复杂度。
- 用检查点和恢复机制处理失败。
- 用 eval 和 trace 判断系统是否真的变好。

## 本指南的推导关系

后续 50 条主实践和专题扩展都可以从这个基础推出：

- Prompt 与 Instruction：控制任务边界和输出形态。
- 上下文工程与 RAG：给概率预测提供可靠依据。
- 记忆与状态管理：把长期事实和流程状态交给可控系统。
- 工具调用与多 Agent：让模型提出意图，让确定性系统执行和审计。
- 测试、评测与验证：用数据衡量概率系统的行为质量。
- 反馈闭环与迭代：让系统在真实环境中持续改进。
