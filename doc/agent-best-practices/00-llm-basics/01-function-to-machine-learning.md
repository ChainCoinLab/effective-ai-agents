# 01. 从函数到机器学习

[返回本章](README.md)

## 核心问题

机器学习最开始到底在学什么？

## 推导线索

```text
想用输入 x 得到输出 y
→ 先假设存在一个函数 f(x)=y
→ 从最简单的线性函数 y=wx+b 开始
→ 预测值和真实值之间会有误差
→ 损失函数把误差变成可优化的数值
→ 梯度下降不断调整参数
→ 训练就是让函数越来越接近数据里的规律
```

## 本节要讲清楚

- 模型是什么
- 参数是什么
- 训练是什么
- 损失函数是什么
- 梯度下降为什么能优化参数
