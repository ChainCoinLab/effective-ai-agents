# 00.6 MCP 概念与原理

[返回全局摘要](../README.md) · [返回本组：AI 工程基础知识与原理](README.md)

MCP 是 Model Context Protocol，即模型上下文协议。它的核心目标是用标准方式把外部资源、工具和提示模板暴露给 AI 应用或 Agent。

## MCP 解决什么问题

没有统一协议时，每个模型、每个应用、每个工具都可能要写一套适配，形成大量定制连接。MCP 解决的是连接标准化问题：

```text
模型 / Agent
  -> MCP Client
  -> MCP Server
  -> Resources / Tools / Prompts
```

它让 Agent 能以统一方式发现资源、读取上下文和调用工具。

## 三类核心能力

| 能力 | 含义 | 示例 |
| --- | --- | --- |
| Resources | 可读取的上下文资源 | 文件、文档、数据库记录、配置、知识材料 |
| Tools | 可调用的动作能力 | 搜索、查询、代码执行、创建工单、业务 API |
| Prompts | 可复用提示模板 | 固定分析模板、生成模板、查询模板 |

## MCP 和工具调用的关系

工具调用是一种能力形态，MCP 是一种连接协议。模型可以通过其他方式调用工具，但 MCP 给工具发现、描述、调用和权限管理提供了统一边界。

```text
工具调用：模型想执行某个动作
MCP：用标准协议暴露和调用这些动作
```

## 工程关注点

MCP 上线不能只关注“接通了”。更重要的是：

- 权限：谁能看见哪些资源，谁能调用哪些工具。
- 最小权限：只暴露必要能力。
- 工具分级：只读工具、写工具、高风险工具分开。
- 审计：记录谁调用、何时调用、输入输出是什么。
- 降级：工具超时、失败或不可用时怎么办。
- 人审：高风险动作必须确认。
