# 00.4 提示词与指令基础

[返回全局摘要](../README.md) · [返回本组：AI 工程基础知识与原理](README.md)

Prompt 是给模型的输入提示，Instruction 是更明确的任务指令、规则和约束。中文里可以直接叫“提示词与指令”。后面实践模块里的 “Prompt 与 Instruction” 可以理解为“提示词与指令工程”。

## Prompt 和 Instruction 的区别

| 概念 | 重点 | 示例 |
| --- | --- | --- |
| Prompt | 提供上下文、问题、目标或示例 | “请总结下面这段会议记录” |
| Instruction | 明确模型必须遵守的规则、边界和输出要求 | “只基于给定材料回答；无法判断时输出 unknown；结果必须是 JSON” |

Prompt 往往偏“输入和任务”，Instruction 更偏“规则和控制”。

## 常见组成

一个工程化提示通常包含：

- 任务目标：要完成什么。
- 背景上下文：可参考的信息。
- 角色边界：模型应该以什么职责工作。
- 约束条件：不能做什么，缺信息时怎么办。
- 输出格式：Markdown、JSON、表格或特定 schema。
- 示例：少量高质量输入输出样例。
- 验收标准：什么结果算合格。

## 为什么提示词需要工程化

大模型会根据上下文概率生成结果。如果指令含糊、上下文混乱、格式不稳定，就容易出现：

- 输出风格漂移。
- 编造缺失信息。
- 忽略边界条件。
- 格式无法解析。
- 无法稳定复现。

因此提示词不是随手写一句话，而是需要版本管理、评审、测试和回归。

## 和 Skill 的关系

Prompt 可以是一次性输入，Skill 则是可复用能力包。一个 Skill 里可以包含多个 Prompt 模板、工具使用流程、检查清单和输出规范。

```text
Prompt / Instruction：控制一次模型调用
Skill：沉淀一类任务的完整执行方法
```
