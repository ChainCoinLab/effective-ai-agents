# 05. 为什么预测下一个 token 会产生能力

[返回本章](README.md)

## 核心问题

只是续写文本，为什么会出现理解、知识和推理？

## 推导线索

```text
要预测好下一个 token
→ 必须学会语法和搭配
→ 必须理解上下文里的指代和关系
→ 必须记住大量事实和常见模式
→ 必须学会不同任务的文本格式
→ 数据、参数和训练规模扩大后，能力逐步增强
```

## 本节要讲清楚

- 语言能力从哪里来
- 知识为什么会被压进参数
- in-context learning 是什么
- 为什么规模变大会出现更强泛化
- 为什么模型仍然会幻觉

## 连接到下一节

预测下一个 token 需要理解上下文。接下来要问：模型怎么知道前文里哪些 token 更重要？这会引出 Attention。
