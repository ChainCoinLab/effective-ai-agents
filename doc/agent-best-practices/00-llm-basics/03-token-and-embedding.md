# 03. 从文字到 token 和 embedding

[返回本章](README.md)

## 核心问题

文字怎么变成模型能计算的东西？

## 推导线索

```text
文字不能直接输入模型
→ 最朴素的办法是给每个词或字编号
→ 编号没有语义距离
→ one-hot 可以表示身份，但太稀疏，也表达不了相似性
→ embedding 把 token 放进连续向量空间
→ 语义相近的 token 可以拥有更接近的向量表示
```

## 本节要讲清楚

- token 是什么
- tokenizer 为什么存在
- one-hot 的问题
- embedding 的直觉
- 语义相似性如何通过向量关系表达
