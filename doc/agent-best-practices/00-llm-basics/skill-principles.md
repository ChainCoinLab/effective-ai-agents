# 00.7 Skill 概念与原理

[返回全局摘要](../README.md) · [返回本组：AI 工程基础知识与原理](README.md)

Skill 是面向 Agent 的可复用能力包。它把某类任务的经验、流程、工具用法、检查清单和输出规范沉淀下来，让 Agent 遇到同类任务时按标准方法执行。

## Skill 解决什么问题

很多任务不是缺模型能力，而是缺稳定流程：

- 每次都要重新解释怎么做。
- 工具调用顺序不稳定。
- 输出格式容易漂移。
- 失败处理靠模型临场发挥。
- 团队经验无法沉淀和复用。

Skill 的作用是把这些经验固化成可加载、可维护、可评审的模块。

## 一个 Skill 通常包含什么

| 内容 | 作用 |
| --- | --- |
| 触发条件 | 什么任务应该使用这个 Skill |
| 操作流程 | 先做什么、后做什么、失败怎么处理 |
| 工具说明 | 需要哪些命令、脚本、API 或 MCP 工具 |
| 领域知识 | 专项任务里的概念、约束和判断标准 |
| 输出规范 | 最终结果的结构、格式和质量标准 |
| 验证清单 | 如何判断任务完成且结果可信 |

## Skill 和其他模块的关系

| 对比 | 边界 |
| --- | --- |
| Skill vs Prompt | Prompt 控制一次调用，Skill 组织一类任务 |
| Skill vs Agent | Agent 是执行主体，Skill 是可加载方法 |
| Skill vs MCP | Skill 描述怎么做，MCP 提供能调用什么 |
| Skill vs RAG | Skill 沉淀流程和方法，RAG 提供事实证据 |

## 示例

“分析一个视频并生成专题文档”可以是 Skill：

- 触发条件：用户给出视频链接并要求分析。
- 操作流程：下载视频、转写音频、抽取关键帧、整理主题、生成文档。
- 工具说明：使用下载器、转写脚本、图片分析、Markdown 写入。
- 输出规范：有来源、章节、截图、总结和实践建议。
- 验证清单：图文对应、内容不编造、代码来自实际画面。
