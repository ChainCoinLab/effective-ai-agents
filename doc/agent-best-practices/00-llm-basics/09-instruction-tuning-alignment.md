# 09. 从续写模型到指令模型

[返回本章](README.md)

## 核心问题

模型怎么从“会续写”变成“会听话”？

## 推导线索

```text
预训练让模型学会语言规律和知识模式
→ 但用户要的是按任务回答
→ 构造 instruction-response 数据
→ SFT 让模型学习指令和回答格式
→ 人类偏好不只看对错，还看有用性、安全性和表达方式
→ RLHF / DPO 让模型更符合人类偏好
```

## 本节要讲清楚

- instruction tuning 是什么
- SFT 是什么
- reward model 的作用
- RLHF 的基本思路
- DPO 为什么更直接
- 对齐和能力的区别
