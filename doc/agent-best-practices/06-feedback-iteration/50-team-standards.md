# 50 最佳实践固化成团队规范

[返回全局摘要](../README.md) · [返回本组：反馈闭环与迭代](README.md)


## Rule
经过验证的 Agent 最佳实践应写入团队规范、模板、检查清单和发布流程，而不是依赖个人经验。

## Why
AI 系统复杂度高，口头经验容易丢失。规范化能让新成员、跨团队协作和长期维护保持一致质量。

## Optimize
把实践沉淀到 PR checklist、eval 模板、prompt 规范、工具接入标准、发布门禁和事故复盘模板中。

## Verify
定期检查新项目和变更是否引用这些规范，并根据真实失败更新规范内容。
