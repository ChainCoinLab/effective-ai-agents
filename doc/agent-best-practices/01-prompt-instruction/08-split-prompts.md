# 拆分 Prompt

[返回全局摘要](../README.md) · [返回本组：提示词与指令](README.md)


## Rule
将复杂任务拆成职责清晰的多个 Prompt 或多个步骤，而不是塞进一个超长 Prompt。

## Why
单个 Prompt 承担过多职责时，调试困难，错误来源不清，部分修改也容易影响全局行为。

## Optimize
- 按意图识别、检索、推理、生成、校验拆分。
- 为每段 Prompt 定义输入输出契约。
- 只在需要全局一致性时保留共享规则。

## Verify
- 单独评测每个 Prompt 的结果。
- 检查步骤之间的数据传递是否完整。
- 对端到端链路运行回归测试。
