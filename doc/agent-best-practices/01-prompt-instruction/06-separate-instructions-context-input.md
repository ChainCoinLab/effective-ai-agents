# 分隔指令、上下文和用户输入

[返回全局摘要](../README.md) · [返回本组：提示词与指令](README.md)


## Rule
在 Prompt 中清晰分隔系统指令、参考上下文和用户输入。

## Why
混在一起会降低指令优先级，也增加上下文内容被模型误当成新指令的风险。

## Optimize
- 使用固定标签标明 `Instructions`、`Context`、`User Input`。
- 明确上下文只作参考，不可覆盖系统规则。
- 对用户输入保留原文边界。
- 对 `CLAUDE.md` 这类项目级规则，区分“长期约定”和“任务上下文”：长期约定写稳定边界，任务上下文放到本次消息或专门文档。

## Verify
- 加入包含伪指令的上下文样例。
- 检查模型是否仍遵守系统指令。
- 确认日志能还原三类内容的来源。
