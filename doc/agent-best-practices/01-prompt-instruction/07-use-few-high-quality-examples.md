# 少量高质量示例

[返回全局摘要](../README.md) · [返回本组：提示词与 Instruction](README.md)


## Rule
优先提供少量覆盖关键模式的高质量示例，而不是大量重复或噪声示例。

## Why
示例会强烈影响模型输出。低质量示例会传播错误格式、错误推理和过时业务规则。

## Optimize
- 选择最能代表边界、格式和决策逻辑的示例。
- 示例保持短小，避免引入无关字段。
- 定期移除过时示例。

## Verify
- 对比有无示例时的准确率和格式稳定性。
- 检查示例是否覆盖主要分支。
- 让业务或领域专家审查示例正确性。
