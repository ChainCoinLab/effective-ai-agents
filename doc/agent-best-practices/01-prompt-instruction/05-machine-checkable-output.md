# 输出格式要机器可校验

[返回全局摘要](../README.md) · [返回本组：提示词与指令](README.md)


## Rule
面向系统集成的输出应使用可解析、可校验的结构化格式。

## Why
自由文本难以稳定接入下游系统，格式漂移会造成解析失败和隐性业务错误。

## Optimize
- 使用 JSON Schema、枚举值和必填字段。
- 明确空值、错误和多结果的表达方式。
- 禁止在结构化输出外追加解释文本。

## Verify
- 用解析器和 schema 校验每次输出。
- 覆盖空结果、异常结果和边界字段。
- 统计格式错误率并纳入回归测试。
