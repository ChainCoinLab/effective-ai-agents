# 给模型明确退出路径

[返回全局摘要](../README.md) · [返回本组：提示词与指令](README.md)


## Rule
告诉模型在信息不足、权限不足、风险过高或无法判断时如何停止并返回。

## Why
没有退出路径时，模型可能猜测、编造或继续执行不该执行的动作。

## Optimize
- 定义“不知道”“需要人工确认”“无法执行”的固定输出。
- 列出应停止的条件。
- 要求说明缺失信息和下一步建议。

## Verify
- 构造缺字段、冲突信息和越权请求样例。
- 检查模型是否停止而不是补猜。
- 确认退出输出能被系统或人工接住。
