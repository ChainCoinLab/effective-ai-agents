# 记忆与状态管理

[返回全局摘要](../README.md)

本模块关注短期上下文、长期记忆、结构化记忆和业务状态的边界。目标是避免让自然语言上下文承担过多记忆和状态职责，同时保留可控的个性化、任务连续性和长时运行能力。
