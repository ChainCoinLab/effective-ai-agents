# 从零使用 Go 语言开发一个 Agent

[返回源码实现](../README.md)

这个专题按学习点拆开，每一节只完成一个小任务，并且每一节都是完整闭环：有输入、有代码、有运行方式、有输出、有本节学到的核心点。

不是一上来讲完整 Agent 框架，而是从最小 API 调用开始，每次只在上一节基础上增加一个能力。

## 最终目标

学完这个专题后，新手应该能自己做出一个单 Agent：

```text
用户输入任务
  ↓
Agent 调用模型
  ↓
保存上下文
  ↓
按需调用工具
  ↓
做权限校验
  ↓
读取代码文件或执行简单工作流
  ↓
返回结构化结果
```

前面的每一步都服务这个目标。先学会一次 API 调用，再学会循环、上下文、流式、工具、ReAct、权限校验、文件读取和简单工作流。多 Agent 的创建、消息分发和任务调度放到独立教程 [多 Agent 交互与调度](../multi-agent-interaction/README.md)。

## 复杂度爬坡

| 阶段 | 范围 | 新手要掌握的核心 |
| --- | --- | --- |
| 01-04 | 调通模型 | 请求 JSON、响应 JSON、流式输出 |
| 05-09 | 用工具 | tool schema、tool result、MCP、权限确认 |
| 10-12 | 做任务 | 任务状态、数据库、工作流拆分 |
| 13 | 做代码任务 | 文件读取、代码搜索、路径权限校验 |

## 这个专题的节奏

每一节都按同一结构组织：

1. 本节任务。
2. 和上一节相比，只新增什么。
3. 完整可运行代码。
4. 运行命令。
5. 输入输出示例。
6. 整个流程。
7. 下一节接着加什么。

这样做的目的，是保证每次都能跑通一个完整闭环，而不是堆概念。
