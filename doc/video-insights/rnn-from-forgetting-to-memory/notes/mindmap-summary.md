# 【软核】循环神经网络 RNN：从遗忘到记忆 思维导图提炼

## 中心思想

RNN 用 hidden state 把过去压缩成动态摘要，并用同一套状态更新规则沿时间反复执行。它能处理变长序列，但也因为“摘要容量有限”和“梯度跨时间传播困难”而容易遗忘；LSTM / GRU 通过门控机制改进这条状态线。

## 思维导图

```text
【软核】循环神经网络 RNN：从遗忘到记忆
├─ 1. 为什么需要 RNN
│  ├─ 当前词的意义取决于前文语境
│  ├─ 文本、语音、传感器数据都是序列
│  └─ 只看当前输入、固定窗口、词袋都不够自然
├─ 2. RNN 的最小动作
│  ├─ 输入: 当前 token 向量 x_t
│  ├─ 输入: 上一步 hidden state h_{t-1}
│  ├─ 输出: 新 hidden state h_t
│  └─ 口诀: 读一个，改一次状态
├─ 3. 循环的含义
│  ├─ 不是每个位置一套网络
│  ├─ 是同一个 cell 在不同时间步重复使用
│  └─ 学到的是通用状态更新规则
├─ 4. RNN 可以支持的任务
│  ├─ many-to-one: 最后状态做分类
│  ├─ many-to-many: 每个位置输出标签
│  └─ generation: 输出再作为下一步输入
├─ 5. 训练方式
│  ├─ 前向: token 逐步进入，状态逐步更新
│  ├─ 损失: 一个或多个位置产生 loss
│  └─ 反向: BPTT 沿时间链回传错误
├─ 6. 普通 RNN 的短板
│  ├─ 表示问题: hidden state 是摘要，会丢早期信息
│  ├─ 优化问题: 梯度跨很多时间步会消失或爆炸
│  └─ 长依赖任务会明显吃力
├─ 7. LSTM
│  ├─ Cell State: 更长期的记忆通道
│  ├─ Forget Gate: 旧记忆保留多少
│  ├─ Input Gate: 新候选写入多少
│  └─ Output Gate: 当前暴露多少给输出
├─ 8. GRU
│  ├─ 更紧凑的门控 RNN
│  ├─ Update Gate 混合旧状态和新候选
│  └─ Reset Gate 控制生成候选时参考多少旧状态
└─ 9. 和 Transformer 的关系
   ├─ RNN: 过去压进状态，一步一步传
   ├─ Transformer: token 之间通过 attention 直接相遇
   └─ 根本问题仍是过去如何影响现在
```

## 论点、论据、论证

| 论点 | 论据 | 论证重点 | 我的判断 |
| --- | --- | --- | --- |
| RNN 解决序列上下文问题 | 当前 token 的意义依赖前文，顺序也会改变语义 | 需要状态把过去带到现在 | 成立 |
| RNN 的本质是状态更新规则 | 每步都用同一个 cell 处理当前输入和旧状态 | 参数共享让模型能处理变长序列 | 成立 |
| Hidden state 是摘要，不是完整记忆 | 状态容量有限，会被后续输入改写 | RNN 的能力和限制都来自摘要 | 成立 |
| BPTT 是沿时间展开后的反向传播 | 损失要追责到前面状态更新 | 长序列让梯度传播变难 | 成立 |
| LSTM / GRU 是给状态线加门 | 门控制保留、写入、暴露或混合 | 目标是缓解长期依赖和梯度衰减 | 成立 |
