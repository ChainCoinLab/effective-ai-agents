# 【软核】循环神经网络 RNN：从遗忘到记忆 结构化内容

## 一句话概括

RNN 是一种沿时间重复使用同一套状态更新规则的神经网络：它通过 hidden state 携带过去的信息，但普通 RNN 容易遗忘和梯度不稳定，LSTM / GRU 则用门控机制让有用信息更稳定地跨时间传递。

## 核心问题

同一个当前输入，在不同前文里会有不同意义。例如“训练”可以指健身训练，也可以指模型训练。模型如果只看当前 token，就无法知道该接什么；它必须让过去的信息影响当前判断。

## 论证主线

1. 序列不是孤立点，而是一条时间线。
   图片或表格可以用固定形状输入处理，但文本、语音、传感器数据等序列会受前文影响。顺序也会改变意义，例如同一组词换顺序后语义可能反转。

2. 朴素方法不够自然。
   只看当前 token 会丢掉前文；固定窗口能保留有限上下文，但窗口大小是人为截断；词袋方法缓解长度问题，却丢掉顺序。

3. RNN 的最小动作是“读一个，改一次状态”。
   每一步输入当前向量 `x_t` 和上一时刻状态 `h_{t-1}`，用同一套参数计算新状态 `h_t`。训练学到的不是某张具体状态卡，而是一套状态更新规则。

4. “循环”来自同一套规则在时间上重复使用。
   展开图里看起来有很多 cell，本质上是同一个小网络在不同时间步重复执行，共享同一组权重。序列有多少步，这个更新规则就执行多少次。

5. RNN 的输出形式可以不同，但底层状态链相同。
   可以最后一步输出做情感分类；可以每一步输出做序列标注；也可以把输出 token 再喂回下一步做生成。任务表面不同，核心都是状态沿时间更新。

6. RNN 训练依赖 BPTT。
   错误信号沿展开后的时间链向前回传，不同时间位置的损失最终都修改同一套共享参数。长序列时常用 truncated BPTT 折中训练成本。

7. 普通 RNN 的短板有两类。
   一类是表示问题：hidden state 像摘要，不是录像带，容量有限，早期信息容易被后续输入改写或挤出。另一类是优化问题：梯度要穿过很多时间步，容易消失或爆炸。

8. LSTM 的关键不是“门多”，而是给记忆更直的通道。
   LSTM 把长期记忆 `C_t` 和当前暴露状态 `h_t` 分开，用遗忘门控制旧记忆保留多少，用输入门控制新候选写入多少，用输出门控制当前暴露多少。

9. GRU 是更简洁的门控 RNN。
   GRU 通常不单独分出 Cell State，而是在 hidden state 内部用更新门和重置门混合旧状态与新候选状态。它参数更少、计算更轻，但不保证一定优于 LSTM。

10. Transformer 没有让序列建模问题消失。
    Transformer 改变的是信息传递方式：远处 token 可以直接通过 attention 相遇，不必都压进一张状态摘要卡。但序列建模的基本问题仍然是“过去如何影响现在，现在如何影响未来”。

## 结论

- RNN 的本质是一个共享状态更新规则沿时间反复执行。
- Hidden state 是任务塑形出来的动态摘要，不是完整录像带。
- 普通 RNN 的困难来自“摘要会丢信息”和“梯度很难跨很长时间回传”。
- LSTM / GRU 的门控机制是在回答同一个问题：怎样让有用信息更稳定地穿过时间。
- Transformer 的 attention 改变了信息传递路径，但没有取消序列建模的根本问题。
