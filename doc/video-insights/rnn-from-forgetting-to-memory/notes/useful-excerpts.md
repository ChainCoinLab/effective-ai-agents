# 【软核】循环神经网络 RNN：从遗忘到记忆 有用摘录

## 筛选标准

只保留能复用、能指导行动、能解释判断标准，或能作为后续写作素材的片段；单纯寒暄、重复铺垫和无法验证的泛泛表达不进入核心摘录。

## 可复用观点

- RNN 的状态更像“摘要”，不是“录像带”。它会保留重点，也会因为容量有限丢掉细节。
- RNN 学到的不是某个固定位置的规则，而是任意一步都能复用的状态更新规则。
- 普通 RNN 的两个短板要分开看：状态丢信息是表示问题，梯度传不回去或爆掉是优化问题。
- LSTM 的重点不是门多，而是给长期记忆留出更直的通道。
- GRU 和 LSTM 都是在回答同一个问题：如何让有用信息更稳定地穿过时间。
- Transformer 改变的是信息传递路径，让远处 token 直接相遇；但序列建模的根本问题仍是过去如何影响现在。

## 可复用方法

解释 RNN 时可以按这条路径讲：

```text
语境影响当前词
→ 只看当前输入不够
→ 需要状态
→ 每一步用当前输入和旧状态算新状态
→ 同一套规则沿时间复用
→ 状态是摘要，所以会遗忘
→ BPTT 沿时间回传，所以会有梯度问题
→ LSTM / GRU 用门控改进状态线
→ Transformer 让远处 token 直接建立关系
```

## 可复用操作步骤

1. 先用一个同词不同语境的例子切入，不直接上公式。
2. 再说明固定窗口、词袋等朴素方法为什么不够。
3. 用“状态卡”解释 hidden state，但要提醒它不是可解释标签表。
4. 把循环图展开成时间链，强调参数共享。
5. 再引入公式：`h_t = f(x_t, h_{t-1})`。
6. 讲训练时先讲 BPTT 的画面，再讲梯度消失/爆炸。
7. 讲 LSTM 时先讲“更直的记忆通道”，再讲三个门。
8. 讲 GRU 时突出“更紧凑的门控混合”，不要陷入符号细节。

## 值得保留的表达

- “读一个，改一次状态。”
- “状态不是录像带，而是摘要。”
- “循环图把时间压在一个圈里，展开后才是一条时间链。”
- “LSTM 不是无限记忆，只是让长程依赖更容易被保留下来。”
- “Transformer 让远处 token 可以直接相遇。”
