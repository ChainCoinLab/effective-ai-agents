# 面试官：Prompt Engineering能真正操控大模型的内在认知吗？结构化内容

## 一句话概括

Prompt Engineering 不能真正操控或重塑大模型的内在认知；它只是通过上下文改变当前生成的条件概率，而真正改变长期行为模式需要修改参数，例如 SFT、继续预训练或更底层的训练过程。

## 背景

这个问题容易被误答成“能，因为角色设定会让模型表现不同”。视频强调，这种回答会把“输出行为变化”和“模型认知变化”混为一谈。面试官真正想考察的是你是否理解模型的工作记忆、长期记忆、参数更新和工程选型边界。

## 关键定义

视频中的“认知”不是人类意义上的信念、三观或主观意识，而是模型在数学层面的参数分布、逻辑权重和由训练形成的长期行为倾向。

因此，判断某种技术是否“改变认知”，关键看它有没有改写模型参数：

| 技术 | 作用位置 | 是否改参数 | 更准确的定位 |
| --- | --- | --- | --- |
| Prompt Engineering | 当前上下文、注意力、KV Cache | 否 | 激发已有能力，改变条件概率 |
| RAG | 外部检索内容加入上下文 | 否 | 给模型参考资料，开卷生成 |
| RePE / 表征工程 | 推理过程中的隐层激活/表示方向 | 否 | 推理时干预中间处理过程 |
| SFT / 继续预训练 | 权重参数 | 是 | 改写长期记忆和行为模式 |

## 论证链条

### 1. Prompt 改变的是条件概率，不是长期认知

给模型一个角色设定，例如“你是数学天才”，不会让模型突然获得新的数学能力。它只是把模型已有知识空间里与该角色相关的表达模式激活出来，让模型在当前上下文中沿着某个方向继续生成。

Prompt 的作用类似“探照灯”：照亮预训练中已经存在的某片知识区域。它依赖的是当前会话里的工作记忆，尤其是上下文和 KV Cache。一旦开启新对话，这部分工作记忆会被清空；模型参数没有变化，权重也没有更新。

### 2. RAG 能引入外部知识，但仍不是认知重塑

RAG 会把检索到的文档、知识库或公司内部资料放进上下文，让模型在回答时参考这些材料。它能解决模型预训练时没见过的新知识问题，但更像“开卷考试”。

模型本身没有真正学会这些知识，只是在当前回答中读取并利用了外部材料。离开这些上下文或检索结果，模型的长期参数结构仍然没有变化。

### 3. RePE 比 Prompt 更深入，但仍是推理时干预

表征工程（Representation Engineering, RePE）试图在模型推理时截获并干预隐层表示。例如找到某个与“诚实”相关的向量方向，在生成过程中对中间激活进行调整。

这比 Prompt 更接近模型内部处理过程，可以被描述为“半物理式”的行为干预。但它仍然发生在推理阶段，并没有通过反向传播写入权重，所以不等于改变长期记忆。

### 4. 真正改变认知，需要参数写入

视频认为，只有 SFT、继续预训练等训练过程，才会通过梯度下降和反向传播修改模型权重。参数矩阵是模型的长期记忆；当权重被更新，模型的长期行为倾向才可能被重塑。

类比来说：

| 类比 | 技术 |
| --- | --- |
| 劝一个人按某种方式说话 | Prompt |
| 让一个人带着资料回答问题 | RAG |
| 在他说话过程中直接干预神经活动 | RePE |
| 让他长期学习并形成新能力 | SFT / 继续预训练 |

## 面试回答框架

可以按四步回答：

1. 先定义边界：大模型没有人类意义上的信念或三观，这里说的认知应理解为参数分布、权重结构和长期行为倾向。
2. 给出核心判断：Prompt Engineering 主要作用于当前上下文和注意力分布，本质是改变下一 token 的条件概率，不涉及梯度更新，所以不能真正改写长期认知。
3. 展开工程选型：激发已有能力用 Prompt；引入外部新知识用 RAG；想长期改变行为模式或注入垂直领域常识，需要微调或继续预训练。
4. 加分补充：可以提到 RePE 等表征工程，它通过干预隐层激活影响模型行为，比 Prompt 更深，但仍不是参数级长期学习。

## 结论

面试官要的不是简单回答“能”或“不能”，而是你能否清楚地区分工作记忆和长期记忆。Prompt 能改变当前输出表现，但不能把新知识写进模型参数；真正的认知重塑发生在参数更新层面。
